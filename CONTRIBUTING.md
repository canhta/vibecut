# Contributing

Read [AGENTS.md](AGENTS.md) and follow the [development and delivery workflow](docs/engineering/workflows.md).
Install [rustup](https://rustup.rs/); the pinned toolchain supplies rustfmt and
Clippy. Run the [check that covers your change](docs/engineering/verification.md#checks)
before each commit.

Contributions use [GPL-3.0-or-later](LICENSE). Every contributed commit requires DCO sign-off:
`git commit -s` certifies the [Developer Certificate of Origin 1.1](https://developercertificate.org/).
Check your Git identity and sign only contributions you have the right to submit.
PRs are welcome once the repository is public; external reports can use the issue forms.

Follow the [Code of Conduct](CODE_OF_CONDUCT.md). Report vulnerabilities through
[SECURITY.md](SECURITY.md). Maintainer tasks remain in the [local tracker](docs/agents/issue-tracker.md).
