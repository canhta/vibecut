# Three independent windows

Home, Editor and Long video to shorts are three separate OS windows, not pages or modes of one window. Each owns its size, top bar, title and chrome, and can be opened, focused and closed on its own.

The studied desktop reference already organises its product this way, so its captures are the behavioural reference for each window: we clone the layout and geometry measured per window, and we do not clone its palette or icons, which stay ours. A component or token is shared only through the common kit, never through one window's frame, so a window can be measured, captured and tested alone.

Current contracts live in [UI design](../product/ui.md); [structure](../engineering/structure.md#desktop-app-appsvibecutsrc) owns the app layers.
