# Domain docs

Single context: `GLOSSARY.md` and `docs/adr/` at the repo root. Read the glossary and the ADRs for your area before exploring.

- Use glossary terms in tickets, tests and code. A concept missing from the glossary is either invented language (rename it) or a real gap (add the term).
- When your work contradicts an ADR, say so: _Contradicts ADR-0002 (…), worth reopening because…_
