# AI commands

`subtitle` is an adapter over the [engine subtitle workflow](../../../../../crates/engine/src/subtitles/README.md#subtitle-workflow); `providers` and `model` expose the offline provider and model catalogs. The CLI parses flags and prints local/remote capabilities and upload disclosures; it implements no chunking, consent/cost, transcription, translation, checkpoint or serialization logic. `subtitle` has no signal-to-job-cancel handler: interruption follows crash semantics, and completed ASR windows stay reusable through the content-addressed cache. Local models are never downloaded implicitly; `model download` requires `--yes-download` after printing the exact licence, source, size and hashes. A completed export or subtitle run reports its output paths, not render's detailed receipt.

`chapters` and `fillers` adapt the engine's chapter and filler analysis jobs through the lent text provider. They parse flags, print the exact upload disclosure before any remote request, and map the returned document or candidates and typed refusals to stdout/stderr; segmentation, prompts, chapter snapping and filler matching stay with their engine owners.

`clips` is an adapter over the [shorts suggestion workflow](../../../../../crates/shorts/src/suggestion/README.md). It parses suggestion, ASR, translation and export flags, prints the provider's upload scope before any remote byte leaves the machine, and maps candidates or typed failures to stdout/stderr. It owns no segmentation, prompt, selection, snapping or export logic, and `--provider` never falls back. Remote suggestion credentials are refused before media work. `providers --operation clips` lists the same offline catalog without opening an adapter. Boundary adjustment kinds follow the [CLI contract](../../../../../docs/product/agent-control/cli.md).
