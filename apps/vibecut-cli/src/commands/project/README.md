# Project commands

`control` is an external consumer of the [engine control contract](../../../../../crates/engine/src/control/README.md#control-admission-revisions-and-receipts). One process is one engine Session: it opens the project under the [writer lease](../../../../../crates/project/src/persistence/README.md#writer-lease-and-save-acknowledgement) before reading, holds it through the final save and releases it on exit.

Requests are newline-delimited JSON objects on stdin (`request_id`, `command`, `params`, optional `idempotency_key`, `base_rev`, `api_version`, `registry_hash`, `session_id`). Omitted contract identity is filled from the running catalog; supplied values are still validated by engine admission. Each response line carries the engine `Response` plus the CLI's stable `exit_code`. A frame that cannot become a request returns a safe error envelope. Oversized frames are drained and returned as an in-band `limit` error, so the session continues with earlier accepted edits intact. Revisions, receipts, replay, idempotency conflicts and receipt capacity belong to the engine Session, so keys and epochs live exactly as long as the process.

`project.save` is the explicit save point. `Session::control_lifecycle_save` applies the same envelope, policy, revision, request-ID, key, capacity and receipt rules as every other effect; the CLI only publishes the project and metadata files in its callback. A refused or failed save keeps the session dirty. Success and typed execution errors are both receipted, so the same request replays its error and a retry that must execute again needs a fresh key. Otherwise a changed project and metadata save once on clean EOF; `--no-save` suppresses that save.

`--allow-overwrite` is the trusted grant for `export`, `export_subtitles` and `burn_subtitles` with `overwrite: true`; without it engine policy returns `permission`. `preview.snapshot {time, path}` publishes atomically without clobbering and needs the grant only to replace an existing file. A request cannot supply its own grant. External gesture commands stay refused by engine policy; agents use atomic batches plus undo.

The control session ticks the engine job runner between requests, so `job_status` and `job_cancel` operate on real preview/export jobs. `preview.snapshot` renders the requested frame at canvas size and publishes a PNG without changing project bytes. The CLI registers the active project and metadata paths as protected, so a snapshot destination aliasing them is refused. Transition frames render through the shared compositor. EOF cancels and joins outstanding jobs through the runner's publication fence, and completed outputs are never partially promoted. There is no signal-to-job-cancel handler: interruption follows crash semantics, so the OS releases the lease, in-flight work stops and unsaved edits are lost. Use `job_cancel` for graceful cancellation.

`exec` uses [engine commands](../../../../../crates/engine/src/session/README.md#public-entry-points) and holds the project lease from load through save. Scene commands use the same registry. Export uses the saved active scene (including its derived duration) and [render admission](../../../../../crates/render/src/export/README.md#export-and-publication) through engine jobs, with a fixed 2 GiB aggregate budget.

`captions import` calls the [engine ASS adapter](../../../../../crates/engine/src/subtitles/README.md#ass-caption-import), which parses and maps styles and returns the registered `captions.import` command. The CLI prints counts and line-numbered warnings and applies the command under the same lease/save path. It never reimplements ASS parsing or style mapping.

`cut`, `transcript` and `captions import` build typed `engine::Command` values (`RemovePauses`, `TranscriptDeleteRange`, the ASS import command) and run through the shared [leased-session helper](../../session/README.md), which owns the lease, load, metadata restore, save, `saved()` and metadata-touch rules. No in-process command is named by string id; only `exec` accepts an id and JSON from the caller as the wire boundary.

`reframe <project> --item <id> --target 9:16|1:1|16:9 [--replace-manual] [--dry-run]` opens the media cache and the local YuNet access, runs `reframe.generate` through the registry, prints every shot's source start, analysed key count and fallback reasons, then applies the finished job with `reframe.apply` and saves once. It never reimplements analysis or key emission: the [reframe owner](../../../../../crates/engine/src/analysis/reframe/README.md) and the [command family](../../../../../crates/engine/src/session/edit/README.md#reframe) own them. A missing `yunet-2026may` bundle returns the setup refusal that names `model download`; nothing downloads. `--dry-run` prints the report without editing.

Lifecycle commands share engine's registry. `project new` creates through `project.create`. `project info` acquires the writer lease before reading and reports optional sidecar `metadata`. `exec ... project.set_view_state` writes only metadata and leaves project bytes unchanged. `project.rename` is an edit, and `project.save {}` republishes the project plus metadata. Missing or corrupt sidecars default through project. Busy and conflict refusals keep their typed codes.

Shared-field, blend/opacity and transition edits are ordinary registry commands through `exec` or `control`, with no CLI-specific path. Contracts: [shared fields](../../../../../crates/engine/src/session/edit/README.md#transient-selection-and-shared-fields), [`transition.*`](../../../../../crates/engine/src/session/edit/README.md#video-transitions).

`freeze <project> --item <id> --at SECONDS --dir ABSOLUTE_DIR [--duration SECONDS]` runs the registry command `timeline.freeze_frame` through the registry adapter with the trusted caller, so the engine's output-grant and publication rules apply unchanged. The default hold is 3 seconds. The engine refuses a relative `--dir`. The edit is one undoable step and the project is saved once when it changed; the still's item id is printed. `exec` runs `timeline.replace_media` as an ordinary edit. The [freeze owner](../../../../../crates/engine/src/artifacts/README.md#freeze-frame) owns capture and publication.
