# Properties view

Interface: `show`.

Renders the properties tab strip and its collapsible rows: appearance, audio (volume and
fades), background (a video clip's kind, colour and blur), canvas, colour dialog, effects,
numeric fields, remove background, selection,
speed and text style. The
effects folder adds the Adjust tab's colour wheels and tone-curve editor. It reads the
area's state and returns `Action` values; it writes no project and keeps no state of its
own.
