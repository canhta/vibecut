# Basic sub-tabs

Interface: none; each module adds `Panel` methods the view calls.

The Basic group's clip sub-tabs beside Transform, in the reference order.

| Module | Holds |
|---|---|
| `background` | A video clip's background: kind, colour and blur. |
| `remove_background` | The Remove background tab. |
| `mask` | The Mask row and its shape dialog. |
