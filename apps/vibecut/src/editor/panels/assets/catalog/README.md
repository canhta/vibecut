# Assets catalogue

Interface: the `text` and `transition` modules.

Names the built-in catalogues the browser lists: `text.rs` holds the Text tab's rows (the bundled looks and templates after search, chips and the All/Commercial filter, and the favourites section), `transition.rs` names the transition shelves and renders their cached procedural thumbnails. Both are read-only; the views draw them and the workflows apply the choices.
