# Yours pages

Interface: the `View` methods `favorites`, `my_presets` and `brand_assets`.

The Media tab's Yours group, in the reference's order (capture 2026-11-14b, frame 110956):
Favorites (`favorites.rs`), My presets and Brand assets (`brand.rs`). The three share one
empty face, the 24 px state glyph over one 12 px line centred in the page, with an optional
accent link. My presets shows only that face: clip presets are not built. Brand assets lists
the active brand kit's files by section; a row inserts a copy at the playhead. Behaviour:
[assets](../../README.md#media-sub-navigation). Design: [editor UI](../../../../../../../docs/product/ui/editor.md#media-tile-menu-added-badge-folders-and-favorites).
