# Editor presentation

`editor.rs` is the public `Editor` facade. `editor/state.rs` holds the shared presentation context, `editor/widgets.rs` the automation-recording controls, `editor/timing.rs` tick-grid time formatting, and `editor/frame.rs` window composition and input routing (its `State` owns the rename draft and splitter gesture; `show` returns actions for the frame to route). `editor/crop.rs` is the toolbar Crop modal: it edits a transient `project::Crop` through the shared `crate::crop` control, locked to the selected ratio (Custom resizes freely, Original keeps the source shape), and writes it with one `timeline.set_item_param` patch on Apply, so closing never mutates the project. The read-only `editor::Context` carries session, selection, locale and theme into areas. Each panel receives its full slot including its header strip; the frame supplies only outer insets and draggable gutters. The assets, player, properties, timeline, captions, export and models areas are folder interfaces with private `view` and `workflow` implementations. Responsibilities follow [structure](../../../../docs/engineering/structure.md).

The player keeps its view state and returns requests for the frame to route. The assets State owns navigation drafts and the prepared workflow projection; `show` consumes `editor::Context` and returns Action values routed by the frame.

`Editor::ui` runs without a window or device. `Playback::new` injects `Sources`, which creates render's `SourceProvider`; production uses `FileSources` as export does. `AudioPort::fill` accepts a headless device callback. `Editor::activate` maps stable widget IDs to engine `execute` for every project edit and to app-owned transport, preferences and selection. `inspect` exposes enabled/focus/rect/current view, playing, position, selection, zoom, snapping and the active snap-indicator target. The project is the Session's immutable snapshot. Every interactive control, including each timeline item and trim handle, exposes a locale- and layout-independent `author_id` through AccessKit.
