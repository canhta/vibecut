# Selection

An empty-track drag selects intersecting visible items; Cmd/Ctrl/Shift adds to the selection at gesture entry. Reversing the drag recomputes intersections; Escape cancels an active marquee. Otherwise Escape clears mask points, then keyframes, then items. `selection_scopes` is transient app state and `inspect` reports the most specific active scope. Timeline Shift clicks toggle; ordered media-list Shift clicks extend from the anchor. `timeline.deselect_all` clears every scope. Item selection syncs to Session history before edits and restores on undo/redo; it never enters Project JSON.
