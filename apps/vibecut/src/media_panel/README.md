# Media library

The Media tab is the live asset library. Grid and list share one persisted mode. The sort dropdown orders by name, type, duration or file size, flips direction on the active key, and persists key and direction in the preference store; sorting is stable. File size is filesystem metadata for display only (missing files show none) and never enters the project record. Cards and rows reuse the import cache's decoded thumbnails and capability badges.

Click, Shift range over the displayed order, Cmd/Ctrl toggle and a blank-area marquee share one asset selection with insert and delete; blank click or Escape clears it. The context menu removes the whole selection through `media.remove` after confirmation. In-use assets refuse with a typed reason listing the timeline items; unused removals are undoable and restore the exact records. `media.reveal` (also the clip context menu's Reveal media) switches to the Media tab, scrolls the asset into view and highlights it for 1.5 s without touching project JSON. During an import batch the overlay reports progress and disables view, sort, import and insert; cancel stays available.

A pending import row is emitted before probe/hash and stays transient until validated metadata is added through the engine command. Audio and video follow probing -> ready/unsupported. Restored assets (including undo/redo) start as probing and reopen capabilities in a background import job before timeline insertion; persisted thumbnails come through the same content cache. Missing, changed or refused sources stay blocked.

Queue and editor each keep at most 64 shared thumbnail handles, charged by engine `RetainedThumbnail` for CPU, upload and GPU storage. Undo prunes both owners; entry limits and budget pressure evict images and textures together. Import retries admission after dropping retained thumbnails on pressure. The batch work allowance is 448 MiB (native decoding, codec scratch, packet/probe buffers, hashing, handoff); retained images have separate leases. Media owns the thumbnail/recovery geometry and worker bounds.
