# Kit widgets

Interface: `NumberSpec`, `SectionResponse`, `SliderResponse`, `action_button`,
`badge_button`, `dashed_outline`, `icon_button`, `icon_tab`, `property_row`,
`rail_slider`, `section_header`, `section_header_with`, `segmented`, `slider_stepper`,
`stepper`, `tab_strip`, `text_tabs`, `toggle`, `transport_button`, `value_field`,
`zoom_rail`.

Renders shared controls without application state. Callers keep their labels, tooltips,
automation IDs, preferences and preview/commit/rollback decisions.
