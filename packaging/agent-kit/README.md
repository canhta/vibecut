# Agent kit

Agent Skill and Claude Code plugin manifest for driving VibeCut over MCP or the CLI. Install steps for each agent live in [MCP control](../../docs/product/agent-control/mcp.md#agent-install); this folder holds only the shipped files.

| Path | Holds |
|---|---|
| `.claude-plugin/plugin.json` | Claude Code plugin manifest; the plugin root is this folder |
| `skills/vibecut/SKILL.md` | The edit loop and rules |
| `skills/vibecut/references/` | Hand-written `edit-loop.md` and `safety.md`; `commands.md` is generated by `cargo xtask catalog` from the engine registry and checked by the registry digest test |
| `conformance.json` | Headless MCP conformance script; the `vibecut-cli` MCP test drives it and an agent harness can replay the same steps |
