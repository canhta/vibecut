# Project bundles

`bundle::export(project, destination)` writes a self-contained directory: `bundle.json` (manifest), `project.vibecut` (the ordinary envelope) and `media/<hash>-<name>` copies. The format is a directory, not an archive, so no archive dependency or parser is admitted and any file manager, sync tool or `tar`/`zip` can carry it. The manifest holds `format` (`vibecut.bundle`), `schema_version` (the envelope's `SCHEMA_VERSION`, so a newer bundle is `TooNew` and an older one `TooOld`), `generator` and one entry per asset: `asset`, `name`, lowercase hex BLAKE3 `hash` and copied `bytes`. A stored file name is always derived from `hash` and a `name` that passes the closed rule (no controls, separators or `:*?"<>|`, no trailing dot or space, at most 80 bytes); no manifest text is ever used as a path, so traversal has nothing to reach. Assets with identical content and name share one copy.

Export stages in a private `.vibecut-bundle-*` directory beside the destination, syncs every file, then publishes with one rename; an existing destination is refused, and a failure leaves nothing at the destination. Each copy is hashed after it is written and must equal the asset's recorded hash, so media that changed since import is refused rather than bundled under a wrong identity. Missing media is recorded (`bytes` 0, no file) and reported by `missing()`. The envelope inside the bundle points every asset at its location inside the bundle; original source paths are not written. Media bytes are capped per file (`MAX_MEDIA_BYTES`, 64 GiB) and in total (`MAX_BUNDLE_BYTES`, 512 GiB). Imported LUTs are referenced resources and travel too: each record's directory (`LutRecord::FILES`: canonical cube, original cube, provenance) is copied to `luts/<id>/` with the canonical cube hashed against the record's id and per-file caps (40 MiB cubes, 16 KiB provenance); `luts` in the manifest lists the copied ids and `missing_luts()` the rest. The envelope points each record inside the bundle.

`bundle::import(bundle, destination)` validates before touching the destination: the bundle and its `media/` must be plain directories, `bundle.json` (4 MiB) and `project.vibecut` must be regular files, the manifest must match the project's assets one to one with no duplicate ids, every `hash` must equal the asset's recorded content hash, names must satisfy the closed rule, and equal stored names must declare equal sizes. Links are refused everywhere (`symlink_metadata`, never followed). Each present file's length must equal the declared size; the copy is bounded, synced and hashed against the manifest and asset. A file absent from the bundle is not an error: the asset keeps its identity and hash and is reported by `missing()` so the editor shows its relink state. Files in `media/` that no entry names are ignored. The result is staged and published like export, the project gets a fresh `ProjectId` (importing twice never yields two projects with one identity), and every asset path points inside the new directory. Listed LUTs are re-verified against their ids and extracted to `media/luts/<id>/` (the layout managed library projects use), so the project opens without a missing LUT; an unlisted LUT is reported by `missing_luts()` and keeps its typed render failure until the same content is imported again. Manifest LUT ids must be unique and belong to the project. Save and Save As keep using the lease and atomic writer above; the bundle writes only into its own new directory.
