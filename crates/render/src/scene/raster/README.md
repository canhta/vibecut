# Frame rasters

Pixels the scene draws from sources that are not decoded media. `raster.rs` rasterises and caches caption and text lines; `text_look.rs` resolves a text effect into paint values, picks a bubble's colour and renders the inspector's look samples. `sticker.rs` draws stickers: flag SVGs from `sticker_flags.rs` (one `include_bytes!` row per file under `assets/stickers/flags`) and fetched emoji and icon SVGs from the lent `StickerSource` (`sticker_source.rs`), rasterised at the destination pixel size, and shape stickers drawn through the generated graphic contours. The parent [scene](../README.md) owns placement, opacity and the sticker error contract.
