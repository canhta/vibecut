# Anthropic translator

`anthropic::AnthropicTranslator` implements `Translator` with the same `TranslationWindow` validation and language tables as OpenAI, using `claude-sonnet-5-5`, mode `context-window`. `provider_config(model)` builds the one admitted configuration; `new` admits only backend `anthropic`, the official base URL and the exact settings, so proxies, lookalike hosts and other version paths are refused. Composition resolves the provider key and injects it as `transport::ApiKey`; it is sent as `x-api-key` with `anthropic-version: 2026-10-21` and never serialized or logged.

`anthropic::MessagesClient` is the reusable Messages transport: it owns endpoint, headers, body cap and typed wire errors. Translation sends synchronous Messages with `stream=false`, `thinking={"type":"between_tools"}` (Sonnet 5.5 rejects `disabled`), an 8192 output-token ceiling and a strict `output_config.format` JSON schema. A response must be one complete message with a text block, `end_turn`, no refusal and valid IDs; thinking blocks are ignored. Schema joins transient transport failures as engine-retryable; refusals, incomplete results and auth/quota/consent/cost failures do not retry. No automatic fallback.

Disclosure returns the shared `ai::UploadDisclosure` with the language pair, model, payload bytes, cost bound and named policy/pricing/structured-output links; it does not restate provider terms. Account-specific ZDR, retention and training settings are outside this adapter; users review the linked policy before consenting. Sources checked 2026-11-04: [Messages](https://platform.claude.com/docs/en/api/messages), [structured outputs](https://platform.claude.com/docs/en/build-with-claude/structured-outputs), [data retention](https://platform.claude.com/docs/en/manage-claude/api-and-data-retention), [pricing](https://platform.claude.com/docs/en/about-claude/pricing).

The per-attempt USD upper bound is 344,064 micro-USD ($2 input / $10 output per 1M tokens) with the same byte ceiling as OpenAI; it is deliberately loose. Prompt caching is off.
