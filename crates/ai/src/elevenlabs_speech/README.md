# ElevenLabs speech synthesis

`elevenlabs_speech::ElevenLabsSpeech` is the ElevenLabs adapter for the speech contract. It admits only backend `elevenlabs`, the base URL `https://api.elevenlabs.io/v1` and two models chosen in `ProviderConfig::model`: `eleven_multilingual_v2` (EN/ZH) and `eleven_flash_v2_5` (VI/EN/ZH). Unsupported language/model pairs return `UnsupportedLanguage` before transport; the adapter never switches model, voice or provider. Multilingual v2 returned HTTP 200 with garbled Vietnamese audio, so the VI gate is client-side. `config`, `capabilities` and `estimate` do no IO.

Requests are `POST /v1/text-to-speech/{voice_id}?output_format=pcm_24000` with the exact NFC text, `model_id`, `apply_text_normalization=auto` and optional `voice_settings.speed` in 0.7–1.2. `language_code` is sent only for Flash v2.5. The response is headerless little-endian PCM16 at 24 kHz, decoded to finite mono f32 and validated by the shared seam. Only a complete HTTP 200 body is accepted (other 2xx are rejected as partial), and a declared `Content-Length` must equal the received bytes, since raw PCM has no container length. Voices are an explicit premade/stock allowlist supplied by composition; cloned and professional-clone voices are never listed, selected or guessed.

The estimate is exact for BMP-only VI/EN/ZH input: 40 micro-USD per character for Flash v2.5, 80 for Multilingual v2, minimum one character. The provider does not say whether non-BMP text counts as scalars or UTF-16 units, so such text quotes the larger count as an upper bound. Graphemes are never used for cost. The `character-cost` header is recorded as `billable_characters` but is a billing-unit count, not a price: Flash reports half a unit per character, Multilingual v2 one. Actual cost is the input-character rate (40/80), not header x rate.

Requests over the model limit (10,000 or 40,000 characters) split at cue (newline), sentence or whitespace boundaries. Adjacent chunks send bounded `previous_text`/`next_text` context. Audio is concatenated only after every chunk decodes and validates; cancellation between chunks discards all audio. The provider minimum is charged per request, so split cost is the sum of chunk characters.

The settings fingerprint binds output format, normalization, optional speed and logging mode; the per-request fingerprint also binds model, voice, language/script, continuity and split policy. Composition puts `ElevenLabsSpeechSettings::settings_fingerprint()` in the provider configuration; a different value is refused. Consent names default retention and model-improvement use with dashboard opt-out. Zero retention is requested only with `enable_logging=false`, is Enterprise-only and is reported as requested, never as verified.

`transport::HttpTransport::send_bounded` bounds an audio response while it is read. The cap derives from the approved duration and the shared 64 MiB decoded-PCM ceiling. `UreqTransport` enforces it during the read; the default trait method checks after buffering.

Tests: `cargo test -p ai --test it elevenlabs_speech::` replays fixtures (see `tests/fixtures/elevenlabs-speech/`); CI makes no network call. The ignored `live_elevenlabs_speech_uses_production_transport` needs `VIBECUT_LIVE_AI=1`, `ELEVENLABS_API_KEY` and a premade `VIBECUT_ELEVENLABS_VOICE_ID`, and synthesizes one bounded probe each in VI, EN and ZH. Live voice quality is unverified.
