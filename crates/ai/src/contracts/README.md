# Provider contracts

`ProviderConfig::new` and serde validate schema version 1, nonempty provider, model/settings identity and tagged `location` (`kind: local` or `remote`). Remote URLs require HTTPS and reject embedded credentials, query and fragments. Backend names are extensible data. `auth_ref` is an external secret-store reference, never a key. The settings fingerprint includes every option affecting recognition. Configuration serializes for persistence; Debug redacts endpoint, model reference and auth reference through `NfcText`. Tokens cannot be serialized or deserialized.

`Capabilities` describes an exact model, mode, operation and locale/script. The crate has no built-in language list or implicit locale fallback. Timing units are a resolved set of supported segment/word/character/grapheme/token capabilities; the adapter omits unresolved conditional timing. Other feature flags distinguish supported/unsupported/unknown/conditional. Timing evidence is advertised, fixture-verified or live-verified, with a revision, and does not prove accuracy. Upload limits are direct invocation bytes and duration in integer microseconds; `None` means unknown, never unlimited or zero. Execution passes complete mono audio windows; streaming flags describe adapters without a streaming job protocol. Unsupported capabilities and locale pairs fail before execution.
