# Text

Transcript-text operations over a remote or local text model: translation, chapters, clip suggestions, filler classification, caption emphasis, and the streamed agent chat.

`structured` is the shared strict Responses JSON format and parser; operation owners validate semantic IDs.

| Module | Contract |
|---|---|
| `chapters/` | [Chapter generation](chapters/README.md) |
| `clips/` | [Transcript clip suggestions](clips/README.md) |
| `conversation/` | [Agent chat conversation](conversation/README.md) |
| `emphasis/` | [Caption emphasis selection](emphasis/README.md) |
| `fillers/` | [Filler classification](fillers/README.md) |
| `structured` | Strict Responses JSON format and parser, described above |
| `translation/` | [Contextual text translation](translation/README.md) |
