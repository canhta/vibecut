# Speech synthesis

`speech::SpeechSynthesizer` is the speech adapter contract. `config`, `capabilities` and `estimate` do no IO; `disclosure(&SpeechRequest)` returns the shared `ai::UploadDisclosure` (provider, model, language/script, requested duration, payload bytes, cost ceiling and policy links) or `None` for a local adapter. `synthesize` is blocking, object safe and single attempt, with an explicit `SynthesisConsent` and shared `ExecutionHooks`. Call `speech::synthesize` for preflight, cancellation checks around the adapter and output validation. Directly invoked adapters call `prepare_synthesis` before IO, observe cancellation, bound network/decoder allocation and reject malformed or truncated audio. Adapters: [OpenAI](../openai/README.md), [ElevenLabs](../elevenlabs/README.md#elevenlabs-speech-synthesis). There is no voice listing, fallback, timeline placement or mixing; a future voice listing must be a separate operation with its own disclosure and approval.

`SpeechRequest::new` takes exact NFC text (nonblank, at most 64 KiB), a provider configuration, an explicit stock/built-in voice ID, an exact language/script pair, output format/rate and a positive maximum duration in integer microseconds. `SpeechCapabilities` resolves supported language/script pairs, voice IDs/categories, WAV PCM16/raw PCM16 format-rate pairs, grapheme limit, streaming status, concurrency/rate limits, cost model, fingerprint and the provider policy URL with retention/training/voice-disclosure text. There is no locale or script fallback. Unknown limits are `None`, never unlimited. Provider-specific limits belong to the adapter.

After showing the exact payload, policy and quote, the composition root calls `SynthesisConsent::grant`. The in-memory, non-serializable token binds the request by value, SHA-256 of the NFC text, extended-grapheme count, operation, full provider configuration, voice, language/script, output format/rate, duration ceiling, capabilities/fingerprint/policy disclosure, quoted cost and approved budget. Any change, even a smaller quote or shorter payload, needs fresh approval. Equivalent decomposed Vietnamese normalizes to the same payload.

`SynthesisEstimate` is Free, Exact, UpperBound or Unknown. Unknown, currency mismatch and over-budget quotes are refused before execution; actual cost must fit the quote. Money is integer currency millionths. Approval is per invocation; engine reserves aggregate retry/chunk spending before reusing a token. No provider or model fallback. Tokens constrain cooperating adapters and are not a sandbox.

`SpeechAudio` carries finite mono f32 PCM, the output sample rate and fingerprint, duration rounded up from the sample count to integer microseconds, usage/actual cost and an optional NFC transcript. The shared seam rejects empty, nonfinite or over-64-MiB PCM, wrong rate or identity, inconsistent duration, duration beyond the approved maximum and any transcript differing from the request. A missing transcript is allowed; adapters promising exact transcripts must require it. Cancellation discards all output. Debug omits audio and redacts text and configuration. Error categories include UnsupportedLanguage, UnsupportedVoice, Payload, Auth, Quota, RateLimit, ContentPolicy, Server, Network, Timeout, Cost, OutputRejected and Cancelled.

Wire schemas, live output and voice quality belong to the adapters.
