# OpenAI adapters

## File transcription

`provider_config(model)` builds the one admitted configuration for a model id; `new` admits any bounded remote model ID, backend `openai`, the adapter's exact settings fingerprint and the official HTTPS base URL, so custom processors, proxies, lookalike hosts, regional endpoints, other version paths and forged or stale settings identities are refused. Composition resolves the provider key and injects it as `transport::ApiKey`; it is never serialized, logged or printed, and request headers and body are redacted. The shared [`transport`](../../../transport/README.md) crate stays on `ureq` 2.12.1 because `sherpa-onnx-sys` pins ureq 2. Key storage belongs to app/CLI composition.

`disclosure(scope)` returns the shared `ai::UploadDisclosure`: provider, model, language, audio duration in microseconds, PCM16 WAV upload bytes, the per-invocation USD upper bound and the named policy/docs links. Consent covers the complete scope; a changed payload fingerprint, provider, model, endpoint, language, mode, byte ceiling or operation refuses before transport. A request is built only after capability, audio and consent checks, so no request is built without a token. Uploads are multipart mono PCM16 WAV, the selected `model`, `response_format=json` and a `languages[]` hint. Files are limited to 25 MB and responses to 1 MiB. Consent `max_bytes` bounds the encoded wire payload including the 44-byte WAV header; `AudioWindow` separately admits at most 64 MiB of f32 PCM.

`gpt-transcribe` returns text and detected languages without timestamps. The adapter advertises no timing units, returns one untimed segment per invocation with a stable window-derived ID, and `Recognition::to_transcript` stays unavailable until an explicitly selected aligner supplies timing. Empty speech returns no segments. The adapter never invents coordinates or switches providers.

Timeouts are bounded and redirects disabled. Cancellation is checked before upload, before parsing and before returning; a request already in flight runs to its timeout or response and the result is discarded. No retries. Typed `Network`, `Server`, `RateLimit` (optional `Retry-After`), `Auth`, `Quota`, `Payload` and invalid-response failures propagate to engine. `Error::is_transient` identifies the retryable set; engine's Transcribe/Translate network policy owns attempts and backoff. Auth, quota and payload failures never retry.

## Speech synthesis

`openai::OpenAiSpeechSynthesizer` sends the selected bounded model ID over `POST /v1/chat/completions` on the official base URL, with `modalities: ["text", "audio"]`, `audio: {voice, format: "wav"}`, `store: false` and a system instruction to read the user text verbatim. `provider_config(model)` builds the one admitted configuration and `disclosure(request)` returns the shared `ai::UploadDisclosure`. It advertises the 13 built-in voice IDs only; custom voice objects and `/v1/audio/voices` are refused as voice cloning. Language/script pairs: `vi`/`Latn`, `en`/`Latn`, `zh`/`Hans`; others return `UnsupportedLanguage` before IO.

Text is NFC, at most 64 KiB. The returned transcript is NFC-normalized and compared exactly; a paraphrase, truncation or missing transcript is `OutputRejected`. `finish_reason` must be `stop`: `length` and unknown or missing statuses are `OutputRejected`, `content_filter` is `ContentPolicy`. The completion ceiling is `ceil(max_duration_micros * 20 / 1_000_000) + text_utf8_bytes + 64`, capped at 16,384 output tokens; larger requests return `Payload` before IO. The estimate uses text UTF-8 bytes (an upper bound, graphemes are not) plus a fixed framing allowance, and prices every completion token at the audio rate. Actual cost is reconciled from reported prompt/completion token details, including text output tokens, and must stay inside the quote.

Only mono 24 kHz 16-bit PCM WAV is accepted. When OpenAI writes `0xFFFFFFFF` RIFF/data placeholders, length comes from the body; a finite RIFF size must exactly cover the body (larger is truncation, smaller leaves trailing data, both `OutputRejected`). Wrong channels, rate, bit depth, and odd or truncated chunk data are rejected. Decoded samples are bounded by the approved duration and the 64 MiB PCM cap. Base64 audio can exceed the 1 MiB text ceiling, so `HttpTransport::send_bounded` reads at most the requested cap (`UreqTransport` enforces it; other transports inherit a checked default). The injected transport owns the call timeout (`UreqTransport` uses 120 s; `with_timeout` overrides). Cancellation is checked before transport, after transport and after decoding. No retry, fallback, project edit or voice listing.

Consent names no training, abuse-monitoring logs up to 30 days, Chat Completions audio application state up to 1 hour, organization-approved Zero Data Retention and AI-generated voice disclosure; it never claims zero retention.

Remote model defaults, known rates, unavailable-model diagnostics and unknown-price consent belong to the [provider contract](../contracts/README.md#remote-model-settings).
