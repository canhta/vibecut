# ASS import and style mapping

`interchange/ass/style` maps ASS style records and colours onto cue styles.

`parse_ass(bytes)` imports Advanced SubStation Alpha and SSA text as typed `AssCue` values with an optional static `CueStyle`. It is as forgiving as `parse` and uses the same encoding rules. It reads `[Script Info]` PlayResX/PlayResY (default 384x288), `[V4 Styles]` (SSA alignment 1-3/5-7/9-11, `TertiaryColour` outline, decimal colours), `[V4+ Styles]` and `[Events]` dialogue records. Limits are 16 MiB per document, 100,000 cues and 10,000 styles; a line over 1 MiB is skipped. Warnings keep one-based line numbers and cap at 1,000 with a suppressed count.

Style mapping keeps font family, font size as a ratio of PlayResY, primary, outline and background colours as RGBA, numpad alignment with resolved horizontal and vertical placement, margins as ratios of PlayResX or PlayResY, border style, bold, italic, underline and strikeout. Unknown or missing styles fall back to the default style with a warning. Cue overrides adjust the same fields for `\b`, `\i`, `\u`, `\s` (a bare tag restores the style value), `\fs`, `\an` and `\c`/`\1c`, `\3c`, `\4c` (alpha stays with the style). Tags inside `\t(...)` never apply and text inside a `\p` drawing is dropped. Transform, karaoke, clipping, scaling and animation tags (`\pos`, `\move`, `\fad`, `\t`, `\k`, `\clip`, ...) are stripped and reported. `\N`, `\n` and `\h` become visible text, and override blocks never reach cue text.

Malformed fields, timestamps, zero or backward durations, empty text and unsupported event kinds warn and skip (`Comment` is ignored silently). A font size or margin that is negative, non-finite or over ten script heights is replaced by the default and reported as `limit`. Parsing never panics on truncated input and costs linear time in line count. Engine `captions.import` turns a parsed document into one caption item and one undo step, interning equal cue styles once into the item's shared, bounded table.
