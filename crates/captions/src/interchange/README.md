# Interchange

## SRT, WebVTT and TXT

`parse(bytes, format, source_lang)` accepts up to 16 MiB as UTF-8, UTF-8 BOM, UTF-16LE/BE with BOM, or Windows-1252 fallback. BOM, encoding fallback, malformed-encoding replacements and CRLF/CR conversion warn. UTF-16 without BOM is not detected. Missing SRT counters, comma or dot fractions (1 to 9 digits), omitted hours and missing blank separators are accepted. Bad timings and stray lines warn and skip. Empty text stays in the model. A missing VTT header warns. VTT identifiers are replaced with deterministic ordinal IDs, and settings, header metadata and NOTE/STYLE/REGION blocks are discarded (metadata warns). Inline VTT markup stays literal text.

Zero or backward durations become 1 ms at the same start with a warning. The track stable-sorts by start (ties keep input order), warns on nonmonotonic input, clamps negative starts to zero, and shifts overlaps after the previous cue preserving duration. `SourceRange` rejects zero or backward persisted ranges, including through serde. Arithmetic overflow returns a typed error. Repair positions are sorted cue ordinals, import syntax positions are lines, and position zero is a document-wide warning. IDs and language edit flags survive repair. Repair can return an error after modifying earlier cues.

`Format` serializes as `srt`, `web_vtt` or `txt` for engine command dispatch. `export(track, format, languages)` selects one tag or two distinct tags in display order; missing or empty language text warns and is omitted. TXT is export-only: one cue per line, whitespace compacted, no clock or header, bilingual text joined with " / ". Parsing TXT returns a typed error. Output is UTF-8 with LF, and blank payload lines are removed with a warning. SRT renumbers cues and rejects payload lines resembling timestamps. VTT escapes &, < and > and decodes them on import. Ticks round to the nearest millisecond, ties away from zero. Collapsed durations expand to 1 ms and push following starts; overflow errors. After canonical export, SRT import and export is byte-stable. Sub-millisecond precision and file formatting are not preserved.
