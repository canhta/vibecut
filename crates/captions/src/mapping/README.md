# Edit mapping

`EditMapping::new` validates an ordered list of `(SourceRange, output_start)` pairs. Each pair keeps its source duration at unit speed. Empty mappings, gaps, repeated source spans, signed ticks and overlapping output spans are supported. Output endpoint overflow returns a typed time error. Segment order identifies occurrences and need not match temporal order. The mapping has no persisted schema.

`map_tick` returns every retained occurrence as a `MappedTick` (segment index and output tick). `map_range` returns independent `MappedRange` intersections with source and output coordinates. All bounds are half-open. `inverse_tick` uses the segment identity to recover the source exactly, even for overlapping output spans. Unknown occurrences and output ticks outside the selected segment have no inverse.

`map_cues` rebuilds a `CueTrack` from an original source track. It drops fully cut cues, clips partial intersections without merging gaps, and stable-sorts output starts. It preserves text, language, edit flags and translation references, and never shifts overlaps or calls subtitle repair. Source IDs must be unique. Each output cue gets a deterministic fragment ID: `CueFragmentId::to_id` encodes the occurrence index, `/`, then the unchanged source ID, and `from_id` recovers both. This stays unambiguous when the original ID contains slashes or looks like a fragment.

After changing cuts, build a new mapping and map the original source track again; never map previously clipped output. Normalize stream timestamps to source-asset time before mapping, applying the audio start offset once at that boundary; this module never reapplies stream offsets. Frame-snapped cuts use the time crate conversions. Retiming, media IO and project commands belong to their consumers. Overlapping or negative output cues stay exact here; interchange export applies its own repair policy.
