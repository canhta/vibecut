# Timing spans

`TimingSpans::new` validates ordered, independently timed layers of `SpanTiming` with ordinal identity, raw byte spans, optional source range, native or forced provenance, speaker and confidence. Layers and normalized grapheme correspondences can overlap, while each layer's source time and byte endpoints stay monotonic. Token fragments can cover the same NFC grapheme without losing their raw endpoints. Serialization stores the original raw text and inputs and reconstructs and validates the maps on read. Original provider text is kept only as raw correspondence data; normalized and display text use NFC. Debug redacts all text and raw bytes. Total text, map and span overhead caps at 16 MiB, including aggregate input to segmentation.

`with_display(DisplayVariant)` rebuilds from the original raw source using caller-resolved NFC `DisplayReplacement` phrase ranges, allowing many-to-many Han orthography changes without shifting timestamps by bytes. The variant records its language. Segmentation refuses a change of primary language (translations use `segment_translation`) and emits the selected display language while keeping the recognition language as cue source. No conversion lexicon or automatic Han choice is bundled. Replacement endpoints must preserve graphemes, replacements cannot be empty or compose across neighbors, and a phrase whose graphemes change together is one correspondence.

`groups(profile)` selects the preferred available layer, then tokens, graphemes, characters, syllables, words or segments. Grouping keeps Latin runs intact and joins candidate boundaries crossed by provider spans or converted display phrases. It never divides an existing source range into finer timestamps. Token grouping uses whole display graphemes protected by token boundaries. Uncovered visible raw bytes or missing native ranges yield an untimed group. Segmentation applies its UAX #14 boundary policy to these groups. Translation execution never accepts these source timing spans.

`CueWordTiming` persists exact NFC display-byte correspondence to individual native/forced Word records. `Unverified` never certifies highlight, even when legacy `word_ranges` and token counts happen to match. The proof records the displayed source language and complete source text; edited/translated or mismatched source remains ineligible. Structural read bounds include record overhead and text (16 MiB); render owns current-state eligibility, overlap and shaped-boundary warnings.

A verified record retains its original `source_range` and its required cue-clock `projection`. Mapping clips the projection before translating it, avoiding overflow from invisible word tails; a fully removed word has an explicit `Clipped` projection while retaining native timing and display correspondence. This is distinct from missing recognition timing, which never creates verified correspondence. Eligibility checks that a projected duration does not exceed its retained native range.

Whole-cue proof joining retains original native records and exact byte offsets through the producer’s whitespace separator. It does not clear manual edited flags or certify mixed/unknown pieces. A normalization crossing between joined pieces leaves the result unverified rather than guessing byte offsets.
