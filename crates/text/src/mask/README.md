# Mask coverage

`coverage_signed_distance(width, height, coverage, cancelled)` shares the outline Euclidean distance transform with render's text masks. It accepts exact, finite 0..=1 glyph coverage, returns negative-inside distances in output pixels and preserves fractional edge coverage. Dimensions admit at most 64 Mi pixels. Invalid length or values, allocation failure and cancellation return typed errors; cancellation is checked per input row and transform row and column. A budgeted caller reserves `coverage_signed_distance_bytes(width, height)` for the temporary and returned distance buffers (on 64-bit targets 16 bytes per pixel plus 20 bytes per longer axis plus 4 bytes). The input working image is owned separately.
