# Baseline

A main-revision baseline is an explicit pinned file, never candidate metrics relabelled. `--write-baseline` records the heuristic metrics plus the complete metric identity: source, transcript, resolved pipeline settings, ordered picks and priorities, `k`, language and energy mode. Run it on the pinned main revision. `--baseline` loads and validates the file and refuses a mismatched label set or any identity mismatch with a typed error. A `baseline.json` beside the labels loads automatically (the synthetic fixtures ship one); `--no-baseline` ignores it. With no baseline the report says the main baseline was not measured. The persisted baseline schema is 2.
