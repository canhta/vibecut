# Speed

`Speed` is a constant playback speed in integer thousandths, 0.1x to 100x (JSON: the decimal, rounded once to the nearest 0.001). The thousandths are a `u32`: 100x is 100000, which a `u16` cannot hold, and keeping the 0.001 grid keeps every speed an exact reduced ratio with the same rounding as before; a floating or hundredths representation would lose that. `output_duration` is `floor(source / speed)`. `source_offset` and `output_offset` convert progress with an explicit `Rounding`. `source_within` gives the source span that plays for an output duration without exceeding it (exactly `ceil(output * speed)` from 1x up). A speed is an exact reduced ratio, so no duration accumulates in floating point. Out-of-range or non-finite speeds are `TimeError::InvalidSpeed`.
