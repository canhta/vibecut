# Timecode

`format_timecode` and `parse_timecode` convert between ticks and absolute signed frame labels with explicit DF/NDF mode and typed invalid-label errors. Labels are `[-]HH:MM:SS:FF` for NDF and `[-]HH:MM:SS;FF` for DF. Supported rates are 23.976, 24, 25, 29.97, 30, 48, 50, 59.94 and 60 fps; others return `Unsupported`. DF is accepted only at 29.97 and 59.94, skipping labels 00-01 or 00-03 respectively at each minute except every tenth. At 59.94, FF identifies individual frames (00-59), not binary timecode frame pairs.

Formatting floors to the containing signed frame (a tick just before zero formats as frame -1), and parsing returns the frame's start tick. Hours extend beyond 23 with no day wrap. Parsing requires at least two hour digits, two digits per other field, exact separators, and no whitespace or leading plus. Skipped DF labels and invalid fields are refused. Negative zero normalizes to zero. A frame boundary outside the tick range returns `OutOfRange`, including the frame containing the minimum tick when its boundary is earlier than that tick. These editor labels are not wire-level LTC/VITC addresses.
